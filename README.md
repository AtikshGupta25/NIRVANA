# Upnext AI Opportunity Navigator

Upnext is a student-focused opportunity discovery prototype designed to help students explore hackathons, internships, scholarships, and open-source contribution opportunities.

## Problem

Student opportunities are scattered across multiple platforms. Students may struggle to identify relevant opportunities and decide what to do next.

## Current Features

- Student skills and interests input
- Keyword-based opportunity matching
- Suggested next actions for each opportunity
- Multi-step workflow implemented using LangGraph
- Simple web interface built with Streamlit

## Technology Stack

- Python
- Streamlit
- LangGraph
- Git and GitHub

## How to Run

1. Install Python 3.13 or a compatible version.
2. Install dependencies:

   `python -m pip install streamlit langgraph`

3. Run the application:

   `python -m streamlit run app.py`

## Agent Workflow

1. Retrieve illustrative sample opportunities.
2. Rank opportunities using keyword overlap.
3. Generate a list of next actions.

## Current Limitations

This prototype uses illustrative sample data. It does not fetch or verify live opportunities. Matching is keyword-based and is not an eligibility assessment.

## Open-Source Credits

This project uses the open-source Streamlit and LangGraph libraries. Their respective licenses and documentation should be consulted when redistributing the software.
